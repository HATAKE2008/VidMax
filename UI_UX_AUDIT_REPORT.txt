================================================================================
VIDMAX PLAYER - ANDROID UI/UX & MATERIAL 3 AUDIT REPORT
READ-ONLY AUDIT - NO SOURCE FILES WERE MODIFIED
================================================================================

Scope : All Kotlin/Compose sources under app/src/main/java/com/vidmax/player/
        (~25.5k lines of UI), plus ui/theme, resources and AndroidManifest.
Build : androidx.compose.material3:material3:1.3.1 (app/build.gradle:122).
        SegmentedButton, PullToRefreshBox, ListItem, ModalBottomSheet and
        Modifier.animateItem() are all already available.
        => No new dependency is required for any recommendation in this report.

Reference image note: no external screenshot arrived in this session, so the
app's own captures in assets/screenshots/ and docs/assets/screenshots/ were
used as the visual reference. Findings describe opportunities in the existing
VidMax style - not a literal copy of any reference.

--------------------------------------------------------------------------------
VERIFIED CROSS-CUTTING FACTS
--------------------------------------------------------------------------------
- SnackbarHost exists only in NetworkScreen.kt and OnlineMusicScreen.kt.
  Everything else uses Toast (55 Toast.makeText calls across 12 files).
- PullToRefreshBox exists only in HomeScreen.kt and OnlineMusicScreen.kt.
- Modifier.animateItem() is used exactly once (OnlineMusicScreen.kt:782).
- No SegmentedButton, no NavigationBar, no NavigationRail anywhere.
  ListItem only in OnlineMusicScreen.kt.
  The bottom navigation is hand-built in MainScreen.kt.
- VidMaxTheme (ui/theme/Theme.kt:601) passes colorScheme and typography but
  NO shapes. M3 shapes are default while the UI hardcodes ~15 different radii
  (4dp-50dp). MaterialTheme.shapes is referenced only once in the whole app
  (PlayerControls.kt).
- Legacy palette constants in ui/theme/Color.kt (Background, Surface, CardBg,
  Maroon, Gold, Overlay, theme demo colors) are still imported in
  VideoThumbnail.kt, PlayerControls.kt, SubtitleAudioPanel.kt,
  ModernPlayerScreen.kt, MusicPlayerScreen.kt.
- WindowInsets handling is sparse (only ~10 files) despite enableEdgeToEdge()
  in MainActivity.kt:40.
- Positive baseline worth reusing: ui/components/ModernDialog.kt (badge + pill
  buttons), ui/components/SelectionBottomBar.kt (animated M3 pill bar),
  ui/components/SongCard.kt + ShimmerModifier.kt (shimmer skeletons),
  ui/components/UpdateDialog.kt, ui/components/StreamLinkSection.kt, and
  MainScreen's page transition.

B. MATERIAL 3 ISSUES (SYSTEMIC)
================================================================================
1. No shapes in MaterialTheme (ui/theme/Theme.kt:601) while the UI hardcodes
   ~15 radii. Missing: a single Shapes token set. Suggested: add shapes =
   Shapes(...) and migrate radii. Priority: HIGH.
2. Custom Box/Row+clickable where M3 components exist for buttons, icon buttons,
   FABs, tabs, chips, radio groups, list rows, sliders and sheets. This is the
   dominant gap across every screen. Priority: HIGH.
3. No SegmentedButton anywhere despite multiple hand-built segmented controls
   (Settings dark mode, PlayerSettings chips, Home segment, Sort sheet).
   Priority: Medium.
4. No NavigationBar/NavigationRail; intentional custom nav is fine, but it lacks
   Role.Tab semantics. Priority: Medium.
5. ListItem used only in OnlineMusicScreen; nearly all settings/list rows are
   hand-rolled. Priority: Medium.
6. Selection controls implemented inconsistently: painterResource(ic_radio_*),
   custom PanelRadio, transparent Check, real RadioButton - four idioms.
   Priority: HIGH.
7. Dialogs split into two systems: ModernDialog (badge/28dp/surfaceContainerHigh)
   vs plain default AlertDialog. Priority: Medium.
8. Two hand-rolled bottom sheets (PlayerSettingsSheet:400,
   SubtitleAudioPanel:611) instead of ModalBottomSheet. Priority: HIGH.
9. No SnackbarHost in 12+ files; 55 Toast calls. Priority: Medium.
10. Hardcoded colors/typescale (Color.White, Color(0xFF1E1E1E),
    Color(0xFF2C2C2C), Color.DarkGray, dozens of sp) instead of color roles/
    MaterialTheme.typography. Priority: Medium.
11. Legacy Color.kt palette still imported in 5 files. Suggested: remove
    imports, use roles. Priority: Low.
12. No SearchBar/DockedSearchBar; search is OutlinedTextField/BasicTextField in
    three places. Priority: Medium.
13. Missing disabled/loading states on primary actions (MpvCircleButton, music
    play buttons, online quick-picks, create-playlist confirm, onboarding
    get-started). Priority: Medium/High.
14. Missing content descriptions / hardcoded English CD throughout; several
    icon-only controls have null. Priority: Medium.
15. Edge-to-edge insets under-handled outside the player/Search/
    SelectionBottomBar. Priority: Medium.

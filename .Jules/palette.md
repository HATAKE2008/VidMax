
## 2024-11-09 - [Replace Buggy Custom FAB with Material 3 FAB]
**Learning:** Reinventing interactive components, like a Floating Action Button, with a custom `Box` implementation often leads to missing edge cases and broken state interactions (e.g., pressed state never resetting).
**Action:** Always prefer standard Material 3 components (e.g., `FloatingActionButton`) over hand-rolled interactive implementations to ensure robust UX and accessibility out of the box.
